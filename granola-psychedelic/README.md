# Psychedelic granola

[Play the standalone demo](https://royschwartz.github.io/alignment/granola-psychedelic/)

Restores the saved September 23 psychedelic prototype: wandering upward gains, elastic resisted losses, monochrome contours, ink trails and stippled disintegration. Replay resets; Pause freezes; Reduced motion provides a short still dissolve. Silent and entirely in memory.

The passage is Roy’s supplied “you have a half-eaten granola bar”. The +1 disquiet and −1 rapture effects are temporary demonstrations, not story mechanics. No game saves or manuscript access. Original icon notices are retained in `icons/`.
