# Alignment

[Play](https://royschwartz.github.io/alignment/) · [First-night preview](https://royschwartz.github.io/alignment/preview/?story&test&preview=night) · [Android download](https://royschwartz.github.io/alignment/downloads/Alignment-Stage-1.apk)

Version 1.4.0. Roy’s current authored manuscript, a white phone screen, portrait choice cards and native-size text. Phones fill the available viewport; desktop previews use a 480 × 960 canvas and scroll when needed. The hand flashes briefly when a card is selected. Game audio remains paused.

The separate first-night prototype includes Roy’s dreams and return-to-the-hole sequence with provisional mechanics. Its test link does not save a playthrough. The main game and prototype use separate saves. Authoring tools, history and photo research stay local. Android includes the main game and runs offline.
