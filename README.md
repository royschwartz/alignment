# Alignment

A playable, HyperCard-inspired narrative game. August 6, 1997.

[Play online](https://royschwartz.github.io/alignment/) · [Download for Android](https://royschwartz.github.io/alignment/downloads/Alignment-Stage-1.apk)

Tap to read. Answer the opening prompts, then make a life: work, food, study, friendships, and an increasingly hungry friend. The optional house introduces MADAME, THE PRIESTESS, THE FOOL, and THE SUN.

The chapter contains 96 activities, 520 rotating passages, and 26 mandatory ethical events with 78 responses. Responses shape a hidden personality profile that affects task outcomes and emotional consequences. Once a story event appears, choose a response before ordinary play continues.

The prose is intensely elliptical: concrete details, short fragments, things left unsaid. Stage 1 ends with the relationship, the dream, and the Stage 2 entry; the full second chapter awaits its script.

The log expands. Attributes explain themselves when tapped. Progress saves in your browser on this device, and existing campaigns migrate with an original-save backup. Reading and closing the game do not advance time.

The matching Android app works offline on Android 9 or later. Browser saves and Android saves are separate.

This repository contains the playable static build. GitHub Pages publishes the root of `main`; no build step or external service is required. To preview locally, serve this folder with any static web server.

Original historical IconStack images and their provenance/notice are retained under `icons/`. Their original terms remain applicable. No additional license is granted for the game writing or code.
