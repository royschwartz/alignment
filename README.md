# alignment

A playable, HyperCard-inspired narrative game. The first chapter begins on august 6, 1997.

[Play online](https://royschwartz.github.io/alignment/) · [Download for Android](https://royschwartz.github.io/alignment/downloads/Alignment-Stage-1.apk)

Tap to read. Answer the opening prompts, then choose among three decisions and wait. The log expands, systems unlock as your life develops, and attributes appear through experience. Progress saves in your browser on this device. Reading and closing the game do not advance time.

The Android app works offline on Android 9 or later. Browser saves and Android saves are separate.

This repository contains the playable static build. GitHub Pages publishes the root of `main`; no build step or external service is required. To preview locally, serve this folder with any static web server.

Original historical IconStack images and their provenance/notice are retained under `icons/`. Their original terms remain applicable. No additional license is granted for the game writing or code.
